## Как пользоваться

1. Запустите проект по корневому README и откройте каталог, корзину, раздел обучения.
2. Пройдите уроки 01–07 последовательно. Команды выполняйте из корня репозитория в активированном Python-окружении.
3. После каждого эксперимента запишите своими словами причину результата. Если объяснить не получается, уменьшите пример.
4. Пройдите темы 08–11 и сделайте самостоятельный проект из урока 12.
5. Сравните своё решение с тестами и исходным кодом, а не только с внешним видом страницы.

В репозитории реализован учебный монолит: каталог, корзина в сессии, регистрация, заказы, JSON API и тесты. Платежи, Redis, Celery, полноценный поиск, почтовая инфраструктура и распределённые сервисы рассматриваются как направления развития. Их наличие не предполагается.

Цель — дать прочную основу и рабочие примеры. Ни один репозиторий не заменит практику с реальными пользователями, эксплуатацией и командой; вы сможете самостоятельно расширять этот проект и обосновывать свои решения.
